# gamewide

## A very wide portable graphic library with network support
> *v0.0.1*

This library is still under development.

## Overview

`gamewide` is a graphic library that provides low-level bindings for as many platforms as possible, like but not limited to: PC, Linux, NDS, N3DS, Nintendo Switch, etc. It aims to bring a common library tool available for programming languages such as C, C++, Java (8+) and Python. It aims to be the most cross-platform, easy-to-use and safe graphic library on top, de-prioritizing speed and fancy graphics.

You can find the core binaries of the `gamewide` graphic library for your favorite platform in this repository. Other repositories shall exist for IDE support, code examples and so many other funny things.

## API Reference

### Static global functions

 - `GWInit()`

Video mode, sound and network system initialization.

 - `GWQuit()`

Free memory from API usage, highly recommended at the end of your program.
